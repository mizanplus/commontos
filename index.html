➕ Adding a New Application

1

Copy the template

Duplicate apps/_template/ to a new folder, e.g. apps/telegram-bot/.

2

Edit meta.json

Update the app name, description, icon, and relevant links in meta.json.

3

Fill in the docs

Replace placeholder text in terms-of-service.html and privacy-policy.html.

4

Add a card here

Copy an .app-card block in index.html and point it to the new folder.

5

Push to main

GitHub Actions will deploy automatically. The new URL is live in ~1 minute.
