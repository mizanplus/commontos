➕ Adding a New Application

1

Copy the template

Duplicate apps/_template/ to apps/your-slug/. Keep only the platform sub-folders you need.

2

Fill in meta.json

Set name, slug, description, platforms, and contactEmail. That's the only file to edit.

3

Register in registry.json

Add "your-slug" to apps/registry.json. The hub picks it up automatically.

4

Push to main

GitHub Actions deploys in ~1 minute. The new doc URLs are immediately ready to submit to developer portals.
